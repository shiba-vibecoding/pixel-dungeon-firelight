Скрипты части 1 (айдентика). Пути в них — рабочие пути автора: `/home/claude/pdf` — это корень репозитория, `/home/claude/firelight/p1/out` — выходная папка. Шрифты — Galmuri9/11 в TTF, их делают из `packages/client/public/fonts/*.woff2` через fontTools.
- `logo.py` — буквы словесного знака (по пикселям, текстом) и их свет.
- `brand.py` — костёр, капитель «PIXEL DUNGEON», горизонтальный и квадратный логотипы.
- `fl_scene.py` — сцена Привала в ширину баннера, с героями PD 1.9.
- `p1_brand.py` — логотипы, фавиконки, аватар, загрузчик.
- `p1_banners.py` — Telegram, GitHub, плашки.
- `p1_tokens.py` — токены `--fire-*`.
- `p1_sheet.py` — лист айдентики.
