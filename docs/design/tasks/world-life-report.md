# Живой мир — отчёт

Задание: `docs/design/tasks/world-life.md`. Сдано всё: части 1–10.

- Листы лежат в `packages/client/public/assets/world/`: PNG без сглаживания на прозрачном фоне и атлас JSON того же имени. Сглаженных краёв нет. Полупрозрачность есть только ровными ступенями, у света, дыма, воды, искр и тумана, как у эффектов оригинала.
- Превью ×4 с подписями на тёмном фоне лежат в `docs/design/previews/` под теми же именами.
- Интерфейс (часть 9) добавлен в систему `docs/design/system`: кнопки карты `.pd-mapctl`, тосты находок `.pd-finds` и `PD.find`, карточка спуска `PD.fx.depth` (в клиенте — `depthCard` в `cards.ts`). В системе появились карточки «Спрайты мира», «Кнопки карты и находки» и «Карточка спуска».

## Формат атласа

```json
{ "image": "doors0.png", "animations": { "door": { "label": "…", "note": "…", "frames": [ { "x": 0, "y": 0, "w": 16, "h": 16, "ms": 70 }, … ] } } }
```

- Кадры строки идут слева направо без зазоров, каждая анимация занимает свою строку. `x`, `y`, `w`, `h` — в пикселях листа.
- `ms` — сколько держится кадр. `ms: 0` у последнего кадра значит «остановиться»: дальше в карту пишется обычный тайл, он назван в `note`.
- Порядок кадров, если он не по порядку (качание травы, пульс рамки), и случайные паузы тоже записаны в `note`.
- Листы с цифрой 0–4 делаются на каждый регион, номер как у `tiles0..4.png`. Раскладка у них одинаковая. Исключение — `ambient`: его первые строки свои у каждого региона, а `well`, `altar` и `traps` есть во всех пяти.

## Интерфейс (часть 9) в коде

- Кнопки карты — `.pd-mapctl` и `.pd-mapbtn.in/.out/.all/.hero`, значки — `--spr-map-*` в `bundle.css`. Разметка — в `migration.md`, раздел «Кнопки карты».

- Карточка спуска — `depthCard(ctx, title, region, uiMapImage, regionIndex, cy, width, t, px)` в `packages/client/src/cards.ts` (патч `cards-depth.patch`, файл `cards.ts` с ним уже применён). Таймлайн `TIMELINES.depth`, 2,4 с, кадр 66 мс; спецификация — `canvas-fx.md`. Показывать на глубинах 1, 6, 11, 16, 21, до имени босса.

## Что осталось за кодом

- Где ставить анимации, решает клиент. Предлагаю так. Двери и сундуки проигрываются по событию открытия. Трава качается со сдвигом фазы ветра по клетке. Факелы, фонари и капли — на клетках стены, под которыми есть пол. Блеск — раз в 2–4 с на случайной видимой вещи.
- Белые кадры красятся в цвет игрока через `globalCompositeOperation = "source-atop"` или заранее окрашенную копию листа.
- При `prefers-reduced-motion` циклы стоят на кадре 0, а события сразу дают конечный кадр.
