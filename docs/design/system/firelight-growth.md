# Firelight · кайф от прогресса и предметов (часть 11)

Правила — PD 1.9.2a, без изменений. Меняется только то, как игрок **видит** рост героя и вещи. Все цифры на экранах — из ядра: `growth.ts` читает героя, предметы и эффекты, которые ядро уже присылает.

Показывается только то, что игрок знает:
- уровень вещи — после `levelKnown`;
- проклятие — после `visiblyCursed`;
- вид зелья или кольца — после `kindKnown`;
- неопознанное кольцо не входит в суммы паспорта (`knownHero`, так же устроена карточка голода).

На каждый пункт — 2–3 варианта. Превью: `docs/design/previews/firelight/growth/`, сводные листы — `sheets/`. В каждом пункте помечено, что выбрал бы я, но выбор за вами.

## 6. Общий стиль

**Палитра.** Только токены `ui.css`: `fire-*`, `lit-*`, `stone-*`, `ink`, `good`, `bad`.
- Новых цветов два: известное проклятие `--grow-curse` #a070e0 (тень #5a2c8c) и цвет глифа `--grow-glyph` 94, 200, 192.
- Цвет чар — это `ItemSprite.Glowing` из `view.ts`. Игра уже красит им зачарованные вещи.

**Значки** — `assets/ui/growth/growth-icons.png`, 46 штук, nearest, с обводкой void. Масштаб ×2 = `--u`.
- **8 px** — метки ячейки: новое, тяжело, по силам, «?», проклято, чары, глиф, заметка, ▲, ▼, огонёк, «видел».
- **12 px** — цифры героя: здоровье, сила, точность, уклонение, броня, урон, уровень, опыт, внимательность, кольцо, палочка, золото, глубина, ходы, убийства, опознание, скорость.
- **16 px** — заголовки: голод, отдых, поиск, ловушки, котёл, колодец, лавка, ключ, сила, коллекция, бестиарий, летопись, паспорт, босс, знак мастерства, фильтр, сортировка.

Чары и глиф нарисованы белой маской и подкрашиваются в игре (`.fl-gi.mask`, `--tint`). Категории в фильтрах — настоящие спрайты `items.png`.

**Движение** (`growth.json → motion`):
- каждый момент длится не больше 400 мс;
- кадры идут шагами (`steps()`), без плавного сглаживания;
- ход не блокируется: окно не ждёт, пока доиграет анимация.
- При «уменьшить движение» (`quality.reducedMotion`) сразу показывается конечное состояние, и подсветка держится 1,2 с.
- Превью «reduced» лежат в `reduced/`.

**Звуки** — только существующие из `sfx-synth.ts`, новых нет:

| Момент | Звук |
|---|---|
| уровень | `levelup` |
| сила | `thump`, затем `sparkle` |
| опознание | `found` |
| улучшение | `hammer`, затем `sparkle` |
| зачарование | `evoke` |
| снятие проклятия | `shatter` |
| мастерство | `badge` |
| классовая броня | `equip`, затем `badge` |

Новая вещь — без звука: звук `item` уже есть при подборе.

**Тон.** Темно, у костра. Свет идёт снизу (glow-полосы окон), «прирост» всегда золотой, «было» — камень.

## 1. Рост героя

### Опыт и новый уровень
Правила: уровень требует `5 + 5 × уровень` опыта и даёт +5 к здоровью и к максимуму, +1 к точности и +1 к уклонению. Внимательность растёт до 9-го уровня (`awareness`: 1 + min(уровень, 9)). Карточка показывает ровно это (`levelGain`). После 9-го уровня строки «внимательность» нет — она перестала расти.

| | Опыт | Новый уровень |
|---|---|---|
| **A · Искра** (выбрал бы я) | Тонкая полоса, деления каждые 5 очков: «пипсы» — те же пятёрки, что в правилах. | Полоса вспыхивает, уголь уровня подпрыгивает (`fl-pop`), под HUD выпадает тост-карточка: «11 · +5 ♥ → 70 · +1 точн. → 20 · +1 укл. → 15». Тап по ней открывает паспорт. |
| **B · Костёр** | Полосы нет: уголь уровня наливается жаром снизу. HUD освобождается от строки. | Из угля летят искры, сбоку — пузырь с тем же «что дал уровень». |
| **C · Летопись** | Ряд пипсов, по 5 очков в каждом (уровень + 1 штука). | На карту ничего не выводится: пипсы гаснут, в журнале золотая строка с иконками. |

### Сила
Правила (`actors.ts`):
- каждая недостающая единица: оружие даёт точность ÷1,5 и удар ×1,2 медленнее; броня даёт уклонение ÷1,5 и шаг ×1,3 медленнее;
- лишняя сила добавляет +0…n урона (кроме охотницы); у разбойника лишняя сила сверх брони идёт в уклонение;
- каждое улучшение снижает требование вещи на 1.

| | Как показано |
|---|---|
| **A · Перья** (выбрал бы я) | После зелья силы в рюкзаке у вещей, которые «стали лёгкими» (`nowLight`), красная цифра силы переворачивается в обычную, рядом перо. Сверху список этих вещей. Метка «по силам» держится до первого взгляда. |
| **B · Лестница** | Окно силы: линейка 10…18, над ней вещи на своём требовании, ваш огонёк на вашей силе. Сразу видно, сколько до следующей вещи. |
| **C · Вес** | В карточке тяжёлой вещи — таблица штрафов из правил: «точность ×0,67 → ×1, скорость удара ×0,83 → ×1». Пока уровень вещи скрыт, рядом пометка «16? — для обычной». |

### Паспорт героя
Сравнение «было → стало» идёт от старта класса: уровень 1, здоровье и сила класса, точность 10, уклонение 5, тканевая броня (`passport`).

| | Как показано |
|---|---|
| **A · Паспорт** (выбрал бы я) | Шапка: портрет, имя, «Воин · знак гладиатор», глубина и ход. Строки: иконка, имя, значение, «+N» и полоса камень/золото. Ниже — «с тем, что надето» (точность и уклонение с кольцами, без неопознанных) и надетое с ключевой цифрой. |
| **B · Кукла** | Герой ×7 посередине на отсвете, вещи вокруг, цифры в две колонки с той же полосой. |
| **C · По глубинам** | График 1…26: уровень, здоровье, сила ступеньками, отметки боссов; под ним три главные вехи. |

### Подкласс и классовая броня
Книга мастерства выпадает после Тенгу, набор брони — после Короля гномов.

| | Момент | Дальше в игре |
|---|---|---|
| **A · Печать** | Окно: знак ×5 ставится печатью (`fl-stamp`), название, суть подкласса из `subclassInfo`. | Знак у уровня в HUD, в паспорте, в итогах забега. |
| **B · У костра** (выбрал бы я) | Полоса-баннер через экран, как имя босса: «ГЛАДИАТОР · путь выбран». Над героем в 3D вспыхивает знак (`growth-fx` sigil). | Классовая броня — свой ряд листа героя (ряд 6, уже есть). |
| **C · Глава** | Новая глава летописи: «Глава III · Гладиатор». | Глава остаётся в летописи. |

### Рост на герое в 3D
Ступени улучшения: +1…2, +3…5, +6…9, +10 и выше (`shineTier`). Скрытый уровень не показывает ничего. Чужой герой в кооперативе показывает только то, что известно его владельцу.

| | Как показано |
|---|---|
| **A · Искры** (выбрал бы я) | Искры у оружия: 1–4 по ступени, на 4-й — постоянная орбита и тёплый отсвет у ног. Руна чар цвета `Glowing` прорисовывается у клинка. Глиф — руна на груди. Известное проклятие — лиловая дымка. |
| **B · Отблеск** | Без частиц: полоска света пробегает по фигуре. Чем выше ступень, тем чаще (2,4 / 1,6 / 1,0 / 0,6 с). Цвет — цвет чар; проклятие — мигающий лиловый контур. |
| **C · Круг** | Кольцо на полу: слева 10 делений оружия, справа 10 — брони, цвет чар слева, проклятие — лиловые трещины. Читается сверху и ничего не добавляет на спрайт. |

## 2. Рюкзак

### Метки ячейки
Помещаются в 52 px на 375 px экрана (`slotMarks`).

| | Как показано |
|---|---|
| **A · Уголки** (выбрал бы я) | Сверху слева — уровень «+3 / −2» или «?», пока скрыт. Сверху справа — сила, красная если тяжело, «14?» для типичной. Снизу справа — количество или заряды. Снизу слева одна метка, по старшинству: проклятие → новое → чары (руна цвета чар) → глиф → заметка. |

### Карточка предмета

| | Как показано |
|---|---|
| **A · Было / станет** (выбрал бы я) | Полосы урона «в руке» и «этот». Пока уровень скрыт, полоса пунктирная и с «?». Строка «тяжелее на N: ÷1,5ⁿ точность…». Опознание — 10 делений (`segments`: 20 ударов, 10 принятых, 40 выстрелов, 200 ходов) с пометкой, когда счёт идёт. Заметка игрока. |
| **B · Рядом** | Две колонки — надетое и этот — со стрелками ▲▼ по минимуму, максимуму и силе. |
| **C · Вердикт** | Наверху чипы «▼ макс −16? · тяжелее на 1 · уровень скрыт», цифры свёрнуты. |

### Момент правды
Все моменты не длиннее 400 мс, GIF — в `anim/`.
- **Опознание** — карточка переворачивается: «?»-сторона уходит ребром, выходит настоящая.
- **Улучшение** — вспышка ячейки, цифра «+1 → +2» уезжает вверх и возвращается, шесть искр.
- **Зачарование** — руна прорисовывается и вспыхивает.
- **Снятие проклятия** — лиловая рамка раскалывается на пиксели и осыпается.
- **Зелье силы** — цифры силы переворачиваются по очереди, шаг 40 мс.
- **Новое** — искра в уголке.

| | Где играет |
|---|---|
| **A · Ячейка** (выбрал бы я для улучшения, чар, снятия проклятия и нового) | Прямо в рюкзаке. |
| **B · Карточка** (выбрал бы я для опознания) | На окне предмета. |
| **C · Тихо** | Строка журнала и тлеющая кнопка рюкзака, ничего поверх карты. |

## 3. Знания игрока

### Коллекция
Зелья 12, свитки 12, кольца 12, палочки 13 (`catalog`). Обличья этого забега взяты из `run.labels`.

| | Как показано |
|---|---|
| **A · Витрина** (выбрал бы я) | Сетка. Опознанные подписаны и в золотой рамке. Догадка — курсивом с пером. Встреченные — по цвету или руне. Не встреченные — силуэт «???». |
| **B · Книга алхимика** | Список: обличье, что это или догадка, «выпито ×3 / в рюкзаке / на полу, гл. 6». |
| **C · Исключение** | Таблица «обличье × ещё возможные виды» (`stillPossible`): игрок ставит ✓ и ×, опознанные виды уходят из колонок. Подсказок от игры нет — только пометки самого игрока. |

### Бестиарий
Только встреченные монстры. Факты — то, что игрок видел сам:
- где встретил впервые;
- сколько убил;
- опыт за победу и до какого уровня он идёт (правило, видимое в игре);
- самый сильный удар, который видел;
- описание из Памятки (`examine.ts`).

Здоровье и защита монстра не показываются.

| | Как показано |
|---|---|
| **A · Карточки** (выбрал бы я) | Сетка карточек, боссы в красной рамке, впереди силуэт «??? глубина 15?». |
| **B · По регионам** | Список по регионам: спрайт, первая строка описания, «×N». |
| **C · Трофеи** | Список по убийствам с полосами. |

### Летопись
Записи берутся из эффектов ядра (`chronicleOf`, `descent`):
- уровень, сила;
- первое улучшение;
- чары (`imbued`);
- снятое проклятие;
- босс;
- мастерство, классовая броня;
- опознание, анкх, смерть, победа;
- новая глубина.

| | Как показано |
|---|---|
| **A · Лента** (выбрал бы я) | Вертикальная лента с иконками и ходами, крупные моменты — светлее. |
| **B · Карта спуска** | 26 строк-глубин цвета регионов, на каждой её события, «◂ вы здесь». |

## 4. Как это работает
Образец — карточка голода: значок, состояние, картинка, числа игры, один совет. Числа считаются на месте для этого героя и этой глубины.

| Механика | Что на карточке | Откуда |
|---|---|---|
| Голод | голод с 260, истощение с 360; +10 каждые 10 ходов (разбойник — 12); паёк 260, пирожок 360; при истощении урон с шансом 0,3 за шаг голода | `hungerinfo.ts` |
| Отдых | 1 здоровья в 10 ходов, кольцо восстановления ÷1,2ⁿ; при истощении не лечит | `world.ts` |
| Поиск | 2 хода, все тайники в 2 клетках на виду; шаг находит с шансом внимательности: 10 → 41 % к 9-му уровню (разбойник 15 → 56 %); кольцо обнаружения добавляет радиус | `world.ts`, `actors.ts awareness` |
| Ловушки | 8 видов по цвету с числами глубины; чёрная — сработала | `traps.ts`, легенда — `i18n-guide` |
| Котёл | 3 семени; 1/N — случайное зелье, иначе по семенам | `brewodds.ts` |
| Колодцы | здоровье и осознание — один глоток; превращение — бросить вещь | `world.ts`, `inventory.ts` |
| Лавки | цена × 5 × (глубина ÷ 5 + 1), продажа — по базовой цене; лавки на 6, 11, 16, 21 | `buyPrice`, `itemPrice` |
| Ключи | железный — запертая дверь своей глубины, золотой — сундук, костяной — выход босса | `world.ts`, `inventory.ts` |
| Сила | см. выше | `actors.ts` |

| **A · Карточка** (выбрал бы я) | Таблица с числами. |
