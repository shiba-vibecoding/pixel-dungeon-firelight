Схемы жестов `gestures.png`: 48×96, 6 строк по 3 кадра 16×16 — tap, hold, drag, throw, click, rclick. Показываются ×2 и идут шагами. При reduced motion стоят на среднем кадре.

Указатель `pointer.png` 16×16 смотрит вниз; `.up`, `.left`, `.right` поворачивают его на 90°. Его ставит `PD.point(слой, кнопка, сторона)` снаружи цели, а цели — рамку `.pd-spot`.
