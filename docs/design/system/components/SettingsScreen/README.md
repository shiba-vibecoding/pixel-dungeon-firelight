Кнопка настроек на титуле и окно «Настройки».

- Кнопка — `.pd-corner > .pd-iconbtn.prefs`: шестерёнка PREFS из `icons.png` ×2 в цели 44×44, без подложки, в правом верхнем углу. Не красная.
- `.pd-window.settings` состоит из групп `.pd-set-group` с подписью `.pd-set-head` и строк `.pd-set-row`, каждая не ниже 44 px.
- Громкость — `.pd-steps`: пять кнопок `.pd-step` по 44×44 впритык. Связывает их `PD.steps(row, get, set)`; касание единственной горящей первой выключает звук.
- Варианты выбираются в `.pd-seg`, это radiogroup, его связывает `PD.seg`. Вкл/выкл — `.pd-switch`, ссылки — `.pd-linkrow` (с `.ext`, если открывается браузер). Сброс — `.pd-button.danger` с подтверждением.
- На экране от 880 px окно раскладывается в две колонки `.pd-col`.
