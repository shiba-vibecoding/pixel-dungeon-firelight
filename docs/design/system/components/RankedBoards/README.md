Окно «Рейтинг» `.pd-boards-window`. Пять вкладок: День, Неделя, Арена, Лучшие, Мои. Под вкладками строка пояснения со значком награды, ниже список до 50 мест.

- Строка `.pd-rank`: место, портрет класса, имя (★ покровителя — спрайт `.pd-patron-mark`), очки; второй строкой во всю ширину «Класс · ур. 22 · глубина 24» (у арены — «Класс · волна 23»).
- Места 1–3: медальный цвет у номера и очков и полоса слева.
- Своя строка `.me` обведена золотом. Если она ниже видимого списка, она прилипает снизу (`.pd-ranks-me`) вместе с «Ваше место: 37 из 214».
- «Мои» — полка трофеев 32 px и свои лучшие забеги с датой.
