Кнопки карты и тосты находок на игровом экране.

- `.pd-mapctl` со столбиком `.pd-mapbtn` (`.in`, `.out`, `.all`, `.hero`) стоит справа над логом. Состояния: обычная, `.pressed` или `:active`, `:disabled` на пределе масштаба. «К герою» показывается только после сдвига карты.
- `.pd-finds` — стопка тостов под HUD. `PD.find(box, key, html, { type, ttl, max })` добавляет тост, склеивает повторы в «×N» и держит не больше трёх.
