Игровой экран на мониторе, 1280×800.

- **Сверху слева** колонка `.pd-dcol` шириной 380 px: панель героя `.pd-dhud` (портрет, уровень, здоровье, опыт, сытость, глубина, ключи, эффекты), под ней отряд `.pd-party` из карточек `.pd-pcard` и строка «Ждём: …».
- **Сверху справа** `.pd-dcorner`: журнал, настройки, меню. Под ними — находки.
- **Снизу два острова `.pd-dbar`.** Слева действия: ждать, искать, осмотреть. Справа быстрые слоты 1 и 2 и рюкзак. На кнопках подписаны клавиши.
- **Лог** — слева над действиями, без плашки. Клики сквозь него попадают в карту.
- **Кнопки карты** — колонкой справа над быстрыми слотами.
- **Наведение мыши** ничего не всплывает: клетка под курсором получает тихие уголки, красные над врагом. Узнать, что на клетке, — ПКМ.

Параметры адреса: `?tip=mob|item|cell|ally&lang=en&solo=1` (где курсор).
