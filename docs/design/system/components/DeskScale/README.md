Как держать пропорции на мониторах.

- **Интерфейс** увеличивается только целым числом раз: `ui = clamp(1, min(floor(H/720), floor(W/1100)), 4)`.
- **Тайл карты** подбирается по ширине: `m = clamp(2, round(W/448), floor(H/208))`. Это около 28 клеток по ширине и не меньше 13 по высоте.
- **Ниже 900 px** по ширине остаётся телефонная раскладка.
