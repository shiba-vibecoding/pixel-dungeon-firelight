Окно «Журнал» (`.pd-window.wide`, открывается из меню в игре), две вкладки.

- «Отметки» — `.pd-jrow`: спрайт `.pd-jicon` из `journal.png` (`--j`), название и глубина. Отметки текущей глубины — `.here` (золото), выполненные — `.done`.
- «Каталог»:
  - подвкладки «Зелья», «Свитки», «Кольца», «Палочки»;
  - сетка `.pd-slot`: опознанная вещь — своим спрайтом, неопознанная — `.pd-item.silhouette`, силуэтом цвета `silhouette`;
  - под сеткой `.pd-cat-detail` с полным именем выбранной вещи.
