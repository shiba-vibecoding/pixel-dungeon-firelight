Карточка обучения `.pd-hint` на телефоне. Она стоит над логом, между героем и нижней панелью: героя не закрывает и оказывается рядом с кнопками, на которые показывает.

- **Состав:** шапка (иконка 40 px — портрет, предмет или значок кнопки — и золотой заголовок), 1–2 строки, строка «как» `.pd-hint-how` со схемой жеста `.pd-gesture`, внизу «Больше не подсказывать» и «Понятно».
- **Черта `.pd-hint-time`** укорачивается шагами, пока карточка не уйдёт сама (14 с). Пока палец или курсор на карточке, черта стоит.
- **Стрелка `PD.point`** показывает нужную кнопку, а сама кнопка мигает рамкой `.pd-spot`.
