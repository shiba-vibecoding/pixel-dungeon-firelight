Фильтры и выбор цели в рюкзаке.

- **Фильтр** («Всё», «Зелья», «Свитки», «Снаряжение») не перестраивает сетку: остальные вещи тускнеют (`.pd-slot.dim`), но остаются на местах и по-прежнему нажимаются.
- **Выбор цели для свитка** (`.pd-window.bag.targeting`):
  - вместо фильтров стоит полоса `.pd-bag-target` с вопросом и «Отменой»;
  - подходящие ячейки (`.can`) мигают золотой рамкой в два шага;
  - лишнее затемнено и не нажимается;
  - панель объясняет, что можно выбрать, и что при отмене свиток всё равно пропадёт.
