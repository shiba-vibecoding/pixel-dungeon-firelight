Подсказки при наведении мыши (`.pd-tooltip`):

- **Монстр:** красное имя, полоска здоровья, красные уголки на клетке.
- **Предмет:** золотое имя.
- **Клетка:** название места.
- **Товарищ:** бирюзовое имя.
- **Кнопка:** название и клавиша.

Ниже строкой — что сделают ЛКМ и ПКМ. Подсказка встаёт со стороны, противоположной середине экрана, где стоит герой, и не выходит за края.
