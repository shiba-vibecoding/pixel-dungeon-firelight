Окно «Испытания»: 7 строк `.pd-challenge` с `role="switch"`, иконки 16×16 ×2 из `challenges.png` (`--c` — номер, порядок как в Challenges.java). До первой победы список `.pd-challenges.locked` закрыт: сверху `.pd-lockplate`, вместо переключателей замки, `aria-disabled`. На титуле кнопка «Испытания» стоит рядом с «Новой игрой», на ней кубок CHALLENGE_OFF или ON и число включённых `.pd-ch-n`.
