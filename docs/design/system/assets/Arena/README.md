Оформление «Арены волн» — в стиле тайлов Pixel Dungeon 1.9, по листу на регион: `arena0..4.png` (96×80) и атлас `.json`, как у `assets/world`.

| Ключ | Кадров | мс | Что это |
| --- | --- | --- | --- |
| `gate` | 4 | стоп · 90 · 90 · стоп | ворота-решётка в тайле стены: закрыты → поднимаются → почти → открыты; опускаются в обратном порядке, по 70 мс |
| `brazier` | 4 | 110 × 4 | жаровня с огнём (в канализации зелёным, в залах лиловым); свет — `light.png` окраской огня |
| `banner` | 2 | 600 · 600 | знамя на стене с амулетом Йендора, качается; фаза по клетке |
| `sand` | 6 | статичные | песок арены: 3 простых, кровь, царапины, черта круга |
| `crowd` | 3 | стоп · 160 · 160 | трибуна со зрителями: сидят → ликуют → прыгают; после волны 1,2,1,2 две секунды |

- `arena-icon.png` 16×16 — иконка режима: скрещённые мечи над ямой.
- `badges-arena.png` 48×16 и `badge-arena-5/10/20.png` — значки «Волна 5» (бронза), «Волна 10» (серебро), «Волна 20» (золото), в форме щита, как в `badges.png`.
- `icon-check.png` — галочка готовности.
