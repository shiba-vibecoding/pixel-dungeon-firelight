# Firelight · спрайты в мире HD-2D

Персонажи, питомцы, предметы и облики из магазина — плоские спрайты PD 1.9, стоящие в 3D-мире. Вокселей нет. Числа — в `hd2d-kit.json → sprites`, кадры и лист — `docs/design/previews/firelight/sprites/`.

## Как стоит
- Вертикальный квад, ноги в нижней середине клетки (`FEET_PX`), **откинут на 20°** к камере 70° (`LEAN_DEG`). Поворота по вертикальной оси нет.
- Высота × **1 / cos(70° − 20°) = 1,56** (`LEAN_STRETCH`): на экране сохраняются пропорции рисунка.
- Nearest, alpha test 0,5, 1 пиксель арта = 1/16 клетки. Стена впереди закрывает спрайт по глубине.

## Тень
- Мягкое пятно под ногами: ширина 0,9 ширины спрайта, сжатие 0,42, чёрное 55 %.
- Пятно сдвинуто на 0,08 клетки **от** самого сильного света рядом.
- Летуны (летучая мышь, глаз, светлячок, огонёк) висят на 0,35 и качаются 1,2 Гц ± 0,06; пятно 0,7 ширины и бледнее (× 0,55).
- Карт теней спрайты не отбрасывают (`castShadow: false`), тени от стен остаются.

## Контурный свет (rim)
- Один пиксель арта по краю силуэта со стороны самого сильного света в его радиусе: факел, лава, грибы, акцент босса. Собственный свет героя на самого героя не считается.
- Цвет — цвет этого света. Сила: `0,3 × intensity × (1 − d / distance)² / max(d, 0,6)`, но не больше 0,6.
- Направление округляется до 8 сторон: получается пиксельный кант, а не градиент.
- Свет выбирается на CPU раз в шаг (у героя и видимых мобов). В шейдер уходят два атрибута на экземпляр:

```glsl
// vertex (рядом с aUv): attribute vec3 aRim; attribute vec3 aRimColor; varying vec3 vRim; varying vec3 vRimColor; varying vec4 vRect;
// vRim = aRim; vRimColor = aRimColor; vRect = aUv;           // aRim.xy: -1/0/1 направление, aRim.z: 1 / размер атласа
// fragment, после <emissivemap_fragment>:
vec2 q = vMapUv + vRim.xy * vRim.z;
bool outside = any(lessThan(q, vRect.xy)) || any(greaterThan(q, vRect.xy + vRect.zw));
float edge = outside ? 1.0 : step(texture2D(map, q).a, 0.5);   // этот тексель сплошной, сосед к свету пустой
totalEmissiveRadiance += vRimColor * edge;
```

## Подкраска регионом
- Спрайт освещается как пол (Lambert): его красят окружающий свет и факелы региона.
- Спрайт не темнее собственного света **0,14**: emissive = его же цвета × 0,14.
- Облики, шапки, питомцы и эффекты магазина подкрашиваются так же. Исключение — светящиеся части (`*-glow.png` легендарных обликов, огонёк, светлячок): они идут в emissive и не тускнеют.

Кадры отрисованы просмотрщиком кита с камерой 70° (`?pitch=70&close=1`): канализация (гнолл, крыса, краб), пещеры (громила, летучая мышь, паук), залы (суккуб, глаз, скорпион).
