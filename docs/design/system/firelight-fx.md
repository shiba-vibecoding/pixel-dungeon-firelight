# Firelight · эффекты (часть 6)

Каждый эффект состоит из трёх частей:
- **лист кадров** — PNG, кадры в ряд (иногда в несколько рядов), размеры кратны 16 px, фильтр nearest;
- **свет**, который эффект даёт в 3D, — Three.js `PointLight`;
- **поведение** — летит, вспышка, висит и т. д.

2D-режим берёт те же листы. Свет в 2D — мягкий диск того же цвета с прозрачностью `intensity / 8`.

Все данные лежат в одном файле `packages/client/public/assets/fx/fx.json`:
- `fx` — 78 эффектов: id → лист, кадры, к/с, поведение, смешивание, привязка, свет, тряска, вспышка экрана, имя EN/RU;
- `events` — 62 события ядра (`Effect` из `packages/core/src/floor.ts`) → id эффекта;
- `bossCards` — карточки появления боссов;
- `behaviours`, `blends`, `light`, `shake`, `tint` — описание полей прямо в файле.

Арт рисуют скрипты `tools/art/firelight/p6/` (`build.sh`). Превью лежат в `docs/design/previews/firelight/fx/`:
- `en|ru-1280x800`, `en|ru-375x812` — листы и карточки боссов;
- `frames/` — эффекты в 3D-комнатах при камере 70°;
- `arenas/` — арены боссов, фон для карточек;
- `anim/` — 60 GIF.

Персонажи остаются плоскими спрайтами по правилам `firelight-sprites.md`: наклон 20° к камере 70°, растяжение `1 / cos(70° − 20°)`. Эффекты подчиняются тем же правилам.

## Формат кадра

| Поле | Что значит |
|---|---|
| `sheet`, `w`, `h`, `row`, `frames` | лист, размер кадра, ряд, число кадров |
| `fps`, `loop` | скорость и повтор по кругу |
| `blend` | `add` — сложение: свет, огонь, магия. В 3D это пакет `glow`, в 2D — `globalCompositeOperation = 'lighter'`. `normal` — обычное смешивание: газ, дым, стекло, жидкость, камни. В 3D это пакет `soft` |
| `anchor` | `center` — середина клетки, стоит; `head` — голова снаряда в (10, 8), кадр смотрит вправо; `feet` — у ног фигуры, стоит и наклонён, как спрайт; `floor` — лежит на полу; `feet-floor` — лежит на полу у ног |
| `light` | `color`, `intensity` (физическая шкала r169, как у болтов в `hd2d-kit.json`), `radius` в клетках (decay 1,4), `ms`, `curve` |
| `shake` | `px` — пиксели арта для `fx.shake`, `ms` |
| `tint` | вспышка всего экрана: `color`, `alpha`, `ms` (`fx.flash`) |
| `name` | `en` / `ru` |

Кривые света:
- `flash` — 15 % времени нарастает, остальное гаснет;
- `follow` — свет летит вместе с болтом;
- `along` — свет стоит в середине луча;
- `pulse` — пульсирует с частотой 1,5 Гц;
- `flicker` — мерцает, как огонь;
- `steady` — горит ровно.

Стоячий эффект (`center`, `feet`) ставится как спрайт: квад наклонён на 20°, по высоте растянут на `STRETCH`. Лежачий (`floor`) кладётся плоско на высоте `lift` клетки (по умолчанию 0,02). Сцена держит **один** динамический свет (`LightRig.dynamic`). Его получает эффект с наибольшим `intensity × остаток времени`; остальные светят только своим сложением.

- **Распад** (`bolt.beam`) — луч появляется сразу: `start` у героя, `bolt.beam` повторяется по клеткам пути, `end` у цели, держится 420 мс, затем `bolt.beam.hit`.

- **Стадо** (`bolt.flock`) — без света: овцы не светятся.

## 5. Карточка появления босса

Карточка выходит, когда босс замечает героев (`yell`, `line: 'notice'`). Она заменяет canvas-карточку `cards.ts → bossCard()`. Вёрстка — `packages/client/src/fl-fx.css`, класс `.fl-boss-card`.

Из чего состоит карточка:
- тёмная полоса через экран между двумя янтарными линиями;
- плашка `fx/boss/plate.png` (border-image, slice 10, ×2 на телефоне, ×3 от 900 px);
- портрет `fx/boss/portrait-<босс>.png`, 32×32: кадр 0 спрайта босса на фоне его акцента;
- строка «Глубина N · регион» золотом (на телефоне регион скрыт);
- имя цветом `--fx-boss` (#ff6a4a);
- эпитет под именем.
